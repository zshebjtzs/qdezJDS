# 项目状态仪表盘

> 本文档为 AI Agent 提供项目的整体进度、已知问题和技术债概览。
> Agent 在开始新任务前，应阅读本文档以了解当前状态。

## 1. 已完成功能

- [x] 用户系统：注册、登录、JWT 认证、个人信息管理、头像/背景图上传（含 cropperjs 裁剪 + sharp 多尺寸）、密码修改（强度校验）。
- [x] 论坛：板块分类（内外部）、帖子分页列表（时间/热度排序）、Markdown + LaTeX 编辑器、二级嵌套评论/回复、评论回复分页、帖子权限控制（管理员/版主修改）、删除帖子/评论/回复、板块全站禁言、用户个人禁言/封禁。
- [x] 网盘：私有/公共网盘、部门共享、文件上传下载删除、分页加载、后端搜索（英文不区分大小写）+ 文件名高亮。
- [x] 管理员面板：用户管理（搜索、分页）、封禁/解封（多种类型和期限）、授予/撤销版主、板块禁言控制。
- [x] 用户列表页（分页、搜索）、使用条款/隐私政策页面、404 页面。
- [x] CSS 设计令牌系统（全局变量 + 公共组件类），所有组件已重构为使用令牌。
- [x] 响应式布局（主要断点 768px / 480px）。
- [x] 分页组件（通用，7 按钮模式）。
- [x] 安全：JWT 认证、bcrypt 密码、参数化查询防注入、XSS 防护（DOMPurify）、Helmet、CORS 开发宽松/生产严格。
- [x] 活跃时间自动记录（5分钟频控中间件）。
- [x] API 测试用例文件（test-api.http）。
- [x] 头像/背景图裁剪（cropperjs 前端 + sharp 后端）。
- [x] 帖子详情页 goToPost 跳转功能。
